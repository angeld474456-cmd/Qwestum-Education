# Questum Database

Эта папка содержит структуру базы данных платформы Questum Education.

## migrations

Файлы создания и изменения структуры базы данных.

Пример:

001_initial_schema.sql
002_roles.sql
003_subjects.sql

## seeds

Тестовые данные.

Например:

subjects.sql
grades.sql
demo_quests.sql

Все изменения базы проходят только через миграции.
